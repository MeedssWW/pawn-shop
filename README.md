# Pickaxe Drop

Мобильная HTML5-игра об автоматическом падении кирки через процедурную шахту. Кирка отскакивает от блоков, добывает руду, запускает цепные взрывы, попадает в кузницы и постепенно продвигается к ядру планеты.

## Что реализовано

- пять уровней кирки и постоянные улучшения;
- процедурная шахта, шесть биомов и глобальный путь до ядра;
- руды, кузницы, динамит с цепными реакциями и неразрушимая слизь;
- редкий критический удар, уничтожающий видимую область;
- задания, рекорды, результаты забега и локальное сохранение;
- оригинальные текстуры, фоны, эффекты и процедурные звуки;
- адаптивный портретный интерфейс для телефона и компьютера;
- интеграция SDK Яндекс Игр, Gameplay API и Loading API;
- добровольная rewarded-реклама и редкая полноэкранная реклама;
- пауза игрового процесса и звука при рекламе или скрытии вкладки.

## Локальный запуск

Нужны Node.js 22+ и pnpm.

```bash
pnpm install
pnpm run dev:pages
```

## Тесты

```bash
pnpm test
```

## Сборки

GitHub Pages:

```bash
pnpm run build:pages
```

Сборка для Яндекс Игр использует относительные пути и проходит отдельную автоматическую проверку:

```bash
pnpm run release:yandex
```

Или в Windows сразу собрать готовый ZIP:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-yandex.ps1
```

Результаты:

- `yandex-dist/` — распакованная проверяемая сборка;
- `yandex-release/pickaxe-drop-yandex.zip` — архив для загрузки;
- `yandex-release/media/` — иконка, обложка и скриншоты;
- `yandex-release/CARD_TEXT_RU.md` — готовый текст карточки;
- `yandex-release/UPLOAD_CHECKLIST.md` — последовательность публикации.

Внутри ZIP файл `index.html` находится в корне. Для GitHub Pages используется отдельная конфигурация с базовым путём `/pawn-shop/`; её архив нельзя загружать в Яндекс Игры.

## Управление

- `ЗАПУСТИТЬ КИРКУ` — начать автоматический забег;
- `×1 / ×2` — изменить скорость наблюдения;
- кнопка паузы — остановить или продолжить забег;
- кнопка динамика — включить или выключить звук.

Направлением кирки игрок не управляет — непредсказуемые физические отскоки являются основной механикой.
