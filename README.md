# Pickaxe Drop / Падение кирки

Полноценная браузерная idle-игра: игрок запускает кирку в процедурную шахту, наблюдает за автоматическим падением, добывает руду, попадает в кузницы, запускает цепные взрывы и покупает постоянные улучшения.

## Что реализовано

- процедурная шахта, создаваемая секциями по мере движения камеры;
- пять уровней кирки, HP, отскоки и автоматическое падение;
- земля, камень, твёрдый камень, обсидиан и шесть видов руды;
- кузницы с улучшением кирки и полным восстановлением;
- динамит 3×3 / 5×5 / 7×7 и цепные реакции;
- четыре плавно сменяющихся биома;
- постоянные улучшения, три ежедневных задания и статистика;
- частицы, всплывающие награды, тряска, замедление и процедурные звуки;
- оригинальный растровый атлас из 16 пиксельных текстур и пять отдельных спрайтов кирки;
- переработанная мастерская с предпросмотром кирок, группами улучшений и визуальными уровнями;
- сохранение в `localStorage` с восстановлением после повреждённых данных;
- адаптивный портретный интерфейс для телефона и компьютера;
- безопасная локальная заглушка rewarded-рекламы;
- интеграция SDK Яндекс Игр и `LoadingAPI.ready()`.

## Структура

```text
github-pages/
  index.html
  main.js
  styles.css
  config/gameConfig.js
  core/GameEngine.js
  systems/
    AudioManager.js
    MineGenerator.js
    SaveManager.js
    YandexSDK.js
  ui/UIManager.js
```

Баланс кирок, блоков, руды, генерации и улучшений находится в `github-pages/config/gameConfig.js`.

## Локальный запуск

Нужен Node.js 22+.

```bash
pnpm install
pnpm run dev:pages
```

Откройте адрес, который покажет Vite. Для тестовых команд можно добавить `?debug=1`.

## Проверка и сборка

```bash
pnpm test
pnpm run build:pages
```

Готовая статическая версия появится в `pages-dist/`. Её можно разместить на любом статическом хостинге.

## Публикация на GitHub Pages

Содержимое `pages-dist/` должно находиться в корне публикуемой ветки. В этом репозитории используется ветка `gh-pages`; базовый путь задан как `/pawn-shop/` в `vite.pages.config.ts`.

## Подготовка ZIP для Яндекс Игр

1. Выполнить `pnpm run build:pages`.
2. Заархивировать **содержимое** `pages-dist/`, а не саму папку.
3. Проверить, что `index.html` лежит в корне ZIP.
4. Загрузить архив в консоль Яндекс Игр.
5. Настроить рекламные блоки и карточку игры в консоли.

При обычном локальном запуске `YandexSDK.js` автоматически переходит в безопасный тестовый режим. Основная механика не требует рекламы.

## Управление

- `ЗАПУСТИТЬ КИРКУ` — начать автоматический забег;
- `×1 / ×2` — изменить скорость наблюдения;
- `Ⅱ` — пауза;
- `♫` — включить или отключить звук.

Управлять направлением кирки во время падения нельзя — это осознанная часть механики.
